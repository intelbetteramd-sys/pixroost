# Макеты

Здесь лежат макеты интерфейса Pixroost: один самодостаточный HTML-файл на сценарий или раздел,
светлая и тёмная тема, русские тексты.

Раньше макеты жили на внешнем холсте, теперь он недоступен. Макеты восстанавливаются здесь, в репозитории,
по спецификации из [README дизайна](../README.md), [компонентов](../components.md) и
[информационной архитектуры](../information-architecture.md): те же токены, то же направление
«Сумерки и свет в окне». Так макеты меняются через PR вместе с документами и не теряются.

## Что есть

| Файл | Что внутри |
|---|---|
| [foundation.html](foundation.html) | основа: цвета, шрифты, отступы, сетка и скругления, знак «свет в окне» и временный логотип, общие компоненты Android и Windows в состояниях «по умолчанию», «наведение» / «нажато», «фокус», «недоступно», «ошибка», превью в состояниях «загружается» и «недоступно», группа «Тот же кадр, другое качество», навигация телефона, планшета (`MainNavigationRail`) и ПК, таблицы контраста и зон касания |
| [first-run.html](first-run.html) | первый запуск: Android — приветствие, доступ к фото (все, выбранные на Android 14+, запрещён), облака, ПК (сканер, ожидание, нет камеры), готово; Windows — приветствие, папка архива и раскладка (OneDrive, мало места, папка с фото), папки и облака, телефон (QR, подтверждение с правами, код устарел), готово |
| [feed.html](feed.html) | лента: Android — обычная, прокрутка с быстрым скроллером, фильтр «Нет на ПК», первые дни (проверка галереи, выбранные фото, облако не отвечает, нет сети), пустые состояния, выбор и «Отправить на ПК»; планшет с `MainNavigationRail` и «Где лежит»; Windows — лента с «Где лежит», первые дни и ошибки, пусто, выбор и «Сохранить в архив» |

Экраны остальных сценариев (хранилища, уборка, устройства, настройки) добавим следующими файлами.

## Как открыть

Скачайте файл или клонируйте репозиторий и откройте `.html` в браузере — сервер не нужен.
На GitHub страница показывает исходный код, а не макет.

Вверху страницы:

- **Тема** — светлая, тёмная или обе рядом;
- **Текст 200%** — увеличивает только шрифт, чтобы проверить переносы;
- **Зоны касания** — подсвечивает зону нажатия: 48 dp на Android, 32 px на Windows.

Тема при открытии — как в системе. Шрифты Unbounded и Onest (SIL OFL 1.1, кириллица и латиница) встроены
в файл, иконки и примеры фото нарисованы внутри него: макет открывается без сети и никуда не обращается.

## Правила для новых макетов

- Один файл — самодостаточный: стили и шрифты внутри, без сторонних скриптов, шрифтов и картинок из сети.
- Токены — только из [README дизайна](../README.md#цвета); новый цвет или размер — сначала в документ, с обоснованием.
- Android и Windows, светлая и тёмная тема, русские тексты с настоящими цифрами из сценариев.
- Перед PR — проверка контраста (WCAG AA), зон касания, увеличения текста и ширины 360 px без горизонтальной прокрутки.
  При 360, 412 и 1280 px и тексте 100 и 200% текст не обрезается, не выходит за свою карточку, кнопку или рамку
  устройства, элементы не наезжают друг на друга, слова переносятся по слогам с дефисом, а не посреди слова.
  Обрезка допустима только там, где она задумана: ряд чипов (исключение 5), прокрутка ленты внизу экрана,
  широкие таблицы и сетки состояний, которые прокручиваются внутри своей рамки.
- Решения, которые документы оставили открытыми, помечены на странице меткой «выбор» и собраны в её конце вместе с вопросами.
