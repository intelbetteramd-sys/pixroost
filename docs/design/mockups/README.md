# Макеты

Здесь лежат макеты интерфейса Pixroost: один самодостаточный HTML-файл на сценарий или раздел,
светлая и тёмная тема, русские тексты.

Раньше макеты жили на внешнем холсте, теперь он недоступен. Макеты восстанавливаются здесь, в репозитории,
по спецификации из [README дизайна](../README.md), [компонентов](../components.md) и
[информационной архитектуры](../information-architecture.md): те же токены, то же направление
«Сумерки и свет в окне». Так макеты меняются через PR вместе с документами и не теряются.

## Что есть

| Файл | Что внутри |
|---|---|
| [foundation.html](foundation.html) | основа: цвета, шрифты, отступы и скругления, знак «свет в окне», общие компоненты Android и Windows во всех состояниях, таблица контраста |

Экраны сценариев (лента, хранилища, уборка, устройства, настройки) добавим следующими файлами.

## Как открыть

Скачайте файл или клонируйте репозиторий и откройте `.html` в браузере — сервер не нужен.
На GitHub страница показывает исходный код, а не макет.

Вверху страницы:

- **Тема** — светлая, тёмная или обе рядом;
- **Текст 200%** — увеличивает только шрифт, чтобы проверить переносы;
- **Зоны касания** — подсвечивает зону нажатия: 48 dp на Android, 32 px на Windows.

Шрифты Unbounded и Onest макет берёт из Google Fonts; без сети подставится системный шрифт.
Само приложение кладёт файлы шрифтов в сборку и в Google Fonts не обращается. Других внешних запросов
в макетах нет: иконки и примеры фото нарисованы внутри файла.

## Правила для новых макетов

- Один файл — самодостаточный: стили внутри, без сторонних скриптов и картинок из сети.
- Токены — только из [README дизайна](../README.md#цвета); новый цвет или размер — сначала в документ, с обоснованием.
- Android и Windows, светлая и тёмная тема, русские тексты с настоящими цифрами из сценариев.
- Перед PR — проверка контраста (WCAG AA), зон касания и увеличения текста.
